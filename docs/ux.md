# UX-концепция

## Персоны

### Персона 1: Аня, школьница с frontend-проектом

- Цели: быстро найти человека, который объяснит дизайн и поможет подготовить интерфейс к защите.
- Важно в первые 30 сек: увидеть подходящих партнёров, процент совместимости и ближайший следующий шаг.

### Персона 2: Марк, начинающий дизайнер

- Цели: делиться знаниями по Figma и получить практику TypeScript/Angular.
- Важно в первые 30 сек: понять, кто хочет Figma и что может дать взамен.

## User Stories

1. Как ученик, хочу войти в личный кабинет, чтобы видеть только свои данные и прогресс.
   - Шаги: открыть login, ввести демо-данные, перейти на dashboard.
   - Done-критерий: после входа доступны защищённые роуты, после logout dashboard недоступен.

2. Как ученик, хочу найти совместимого партнёра, чтобы обмен был полезен обеим сторонам.
   - Шаги: ввести навык, выбрать категорию, отсортировать по совместимости, открыть карточку.
   - Done-критерий: список обновляется, карточка показывает навыки и процент совместимости.

3. Как ученик, хочу предложить обмен и запланировать занятие, чтобы договорённость стала конкретной.
   - Шаги: нажать "Предложить обмен", заполнить тему, партнёра, дату и длительность.
   - Done-критерий: offer и session сохраняются через mock API, появляется success-состояние.

4. Как участник группы, хочу добавлять материалы, чтобы команда училась по общим ссылкам.
   - Шаги: создать группу, выбрать группу в форме материала, добавить ссылку.
   - Done-критерий: материал отображается в карточке группы после ответа API.

## Дизайн-система (Taiga UI 4)

- Используемые компоненты: `TuiRoot`, `TuiButton`, `TuiLoader`, `TuiNotification`, `TuiBadge`, `TuiProgress`, `TuiCard`.
- Кастомные компоненты: `PartnerCardComponent`, страницы `Dashboard`, `Profile`, `Groups`, `Login`.
- Визуальный стиль: спокойный рабочий интерфейс, карточки с радиусом 8px, понятные формы, плотная сетка для быстрого сканирования.
- Состояния: loading через `TuiLoader`, success/error через `TuiNotification`, прогресс через `TuiProgress`.

## Приоритеты

- Первый экран после входа: поиск партнёров, совместимость, прогресс и окно предложения обмена из карточки партнёра.
- Вторично: редактирование профиля, группы, материалы, отзывы.
- Сознательно убрано: чат в реальном времени, платежи, сложные OAuth-интеграции, модерация контента.
